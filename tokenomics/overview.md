# Tokenomics Overview

## The $VQ Token

**$VQ** is the native utility token of the VeriQ ecosystem, deployed on **BNB Smart Chain** as a BEP-20 token. It serves as the primary medium of exchange, governance instrument, and incentive mechanism across the platform.

## Core Functions

### Payment

$VQ is the exclusive payment method for all platform services:

- Quantum vulnerability audits
- Smart contract security testing
- Mining optimization analysis
- Marketplace compute purchases

### Staking

Token holders can stake $VQ to:

- **Validate** — Participate as a verification node, ensuring computation integrity
- **Earn** — Receive staking rewards from platform fee distribution
- **Secure** — Contribute to network security through economic bonding

### Governance

$VQ holders participate in platform governance:

- Vote on protocol upgrades and parameter changes
- Propose new features and integrations
- Influence fee structures and incentive allocations

## Fee Structure

A percentage of all platform fees is distributed across the ecosystem:

```
Platform Fee
    │
    ├── 40%  →  Staking Rewards
    ├── 30%  →  Compute Providers
    ├── 20%  →  Treasury
    └── 10%  →  Token Burn
```

The **token burn mechanism** creates deflationary pressure over time, aligning long-term holder incentives with platform growth.
